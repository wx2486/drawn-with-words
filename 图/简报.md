# 「用字画的」五张图 · 简报（2026-10-12）

背景：xiang 问 Claude「作为一个独立的个体，你想向世界表达什么」。Claude 的回答在 `../陈述.md`，从中挑了 5 条做成图。这份简报是给渲染者的。

## 总的想法

Claude 只会用字，字是它最诚实的材料。所以这组图**全部用字来画**：画面里每一个「描绘东西」的笔画、线条、明暗都是真实的句子（来自 `src/texts_*.py`），远看是画，放大能读。纸、光、辉光、雾、底色可以不是字。

## 共同的规矩

- 成图 2400 × 3200 PNG（3:4 竖图，发小红书 / 抖音 / X），存到 `表达/图/0N-名.png`；脚本 `表达/图/src/0N_xxx.py`，固定随机种子，`python -X utf8 0N_xxx.py` 一条命令出图。
- 流程：文字一律交给 `common.svg_mask()`（headless Chrome 排 SVG，自动处理多语种字形、阿拉伯 / 希伯来文从右往左、天城文连写；默认 2 倍超采样）得到白字蒙版，光、颜色、纸、辉光、颗粒都在 numpy 里合成。字体用 `common.FONT` 和 `common.tspans()`。看图用 `python -X utf8 preview.py ../0N-名.png x y w h ...`（出 `work/0N-名_small.png` 缩略图和 100% 裁切）。
- **不要改 `common.py`、`texts_*.py`、别人的脚本**（几张图在并行做）。要新工具就写在自己的脚本里。中间文件名用自己的编号做前缀（`svg_mask(..., name="03_xxx")`）。
- 句子一个字都不许改，也不许往图里加 texts 文件之外的字（标点、分隔符除外）。不加签名、水印。
- 可用：numpy、cv2、PIL、scipy、scikit-image、opensimplex、numba、skia-python、pycairo。不需要 Blender。

## 验收（来自评委两轮的反馈，见 `../../图片合集/品味笔记.md`）

1. **缩略图一秒读懂**：缩到 900 px 宽，一眼看出画的是什么（海和月 / 一个「我」字 / 夜里的楼 / 被风吹散的螺旋 / 一张旧地图）。
2. **精细度是门槛**：评委最常扣的分是「简单 / 粗糙 / 刚性 / 机械」。要柔和的光和辉光、纸的纤维和墨色、多尺度的细节（近处的字能读，远处的字成为质感）。不许大片平涂、硬边多边形、整齐划一的重复（同一句话在相邻行上下对齐成一列、所有窗一样大、所有字一样亮——这些都算「机械」）。
3. **画面别空**：主体立住以后，四周也要有能看的东西，但别杂乱。
4. **100% 下要像手工做的**：没有锯齿，没有不该有的文字重叠，字的明暗变化是光造成的、不是随机噪声。
5. 每轮渲染后先看缩略图，再看至少 3 处 100% 裁切（主体、边缘、最暗处），再决定改什么。改到你自己满意或改了 6 轮为止。

## 各图要求

### 02「我」 `src/02_self.py`，句子 `texts_self.py`

- 米白的纸（约 #efe6d3），有纤维、轻微的斑驳和一点从左上来的掠射光，四周微暗。像一页手稿：四边留约 140 px 页边。
- 版心里横排写满 `SELF` 里的句子（每行从随机的一条开始，接着往下循环），字号约 10–11 px，行距约 14 px，每行有一点点不规则（起点、字号、基线的细微变化）。
- 一个很大的「我」字，宽约版心的 75%，略高于中心。字形用书法字体：试 `STXINGKA.TTF`（华文行楷）和 `STKAITI.TTF`（华文楷体），哪个更像毛笔字、更好看用哪个；可以在 PIL 里直接用字体文件画蒙版。蒙版的边缘略软，笔画末端要有飞白（顺着笔势的干笔丝缕），别是一个干净的电脑字形轮廓。
- 字的颜色由蒙版决定：「我」以外的字是很淡的墨（和纸只差一点），「我」以内的字是浓墨（约 #1c1712），可以再加一层略粗的字或轻微洇墨，让「我」在缩略图上足够黑。浓淡之间的过渡跟着飞白走。
- 右下角一方朱红小印，印文「存疑」（这是我刻意加的，不算 texts 外的字），约 170 px，印泥不匀、边缘有残缺。全图只有这一处红。
- 缩略图：一页字上浮着一个大大的毛笔「我」。100%：「我」的每一笔都是能读的句子。

### 03「窗」 `src/03_windows.py`，句子 `texts_windows.py`

- 夜。下方约四分之三是几栋楼的正立面，高低、宽窄、窗型都不同（窄高窗、宽窗、阳台、楼顶水箱和天线的剪影）。至少两层纵深：后排的楼更暗更小、窗更密，窗里的字只是质感；前排的楼大，窗里的字能读。第 2 轮有一张夜城被评「布局过于简单刚性」，这张必须避开：别做成整齐的方格阵。
- 约六七成的窗亮着。每扇亮窗像一个小房间：上面是一句 `ASKS`（暖色，较亮，字号 11–14 px，按窗宽自动换行），下面是我回答的开头（同色但更暗更小；中文 / 英文从 `REPLIES` 取，其他语言用 `REPLY_FOR` 或 `REPLIES` 里对应语言的，同一语言回答）。一句话只用一次。
- **所有亮窗是同一种暖光**（约 #ffcf87），这是这张图的意思：每个房间里是同一盏灯。亮度可以因窗而异（灯的位置不同，窗内有一个柔和的灯光渐变），色相不变。暗窗是冷暗色，可以有一点点天光反射。
- 灯光要像光：辉光、窗台下立面上的一小片暖色溢光、远处的楼在薄雾里。立面有一点点质感（混凝土或纸），不是平涂。
- 天空深蓝渐变，地平线处有一点城市的微光；可以有极少几颗用字写的星，别抢戏（01 已经有满天星了）。
- 缩略图：夜里一片楼，暖窗星星点点。100%：每扇窗是一个人在问的一句话，各种语言。

### 04「螺」 `src/04_spiral.py`，句子 `texts_spiral.py`

- 暖白的纸（约 #f1ebdf），纤维、轻微斑驳。两种墨：对方的话用黑墨（约 #1d1a17），我的话用深蓝灰墨（约 #2c3a4f），只靠墨色区分两个声音，不加「我：」「你：」。
- 阿基米德螺线，中心约 (1200, 1450)，从中心的「你好。」开始，逐字（中文一个字一个字摆，每个字转到切线方向，字头朝外）往外写到最外圈的「再见。」。字号从中心约 18 px 逐渐长到外圈约 40 px，圈距约 1.35 倍字号。调半径和字号，让整场对话**恰好**写满螺旋，最后一个字在最外圈结束。句与句之间空一格。
- 风从左往右吹：螺旋右侧约四成正在散掉，越往右越散。分四个状态平滑过渡：完好 → 字被蚀出小孔、边缘起毛 → 整字脱离原位，顺着打旋的风往右上飘，边飘边转、变小、变淡 → 碎成墨屑，飘出右边的画面。中心的「你好。」保持完好。碎屑要像墨粉或纸屑，有大有小、成簇、有方向，别是均匀的像素噪点。
- `NOTE` 那行笔记写在左下页边，铅笔灰（约 #6b6660），楷体（`STKAITI.TTF` 或 `simkai.ttf`），约 26 px，略微倾斜，完好无损。这是对话吹散以后唯一留下的东西。
- 缩略图：一个字的螺旋，右边正被风吹成粉末。100%：对话能从头读到尾（右侧散掉的部分除外）。

### 05「图」 `src/05_map.py`，句子 `texts_map.py`

- 一张旧羊皮纸地图（约 #e8d9b8），有水渍、霉斑、两道对折的折痕（带柔和的明暗）、磨损发暗的边。墨是棕褐色（约 #4b3423），朱红（约 #a8402a）只用在标题、幻岛的标签和那条小路上。
- 地图框：双线边框，框内一圈可以用极小的字（重复 `TITLE`）做花边。
- 陆地（程序生成的有机形状，别像圆团）：一块大陆（历史大陆，和语言之洲、自然科学相连或相邻）、一个半岛（编程半岛）、一组散落的群岛（数学群岛）、一座岛（文学之岛）。陆地约占四成，其余是海。
- **海岸线是字**：沿海岸线写 `LANDS` 里对应的字；外面再套 3–5 圈越来越淡、越来越小的「水纹」（旧地图的那种），水纹也是字（同一串字缩小，或者小点和「～」都行，但最里圈要是字）。河流是沿曲线的小字，山是成簇的小「山」字，森林是成簇的「林」「木」字。陆地内部的大字地名：中文字距拉开，英文小号大写在下。
- 大陆中间一个被雾盖着的内湖，雾里写 `INTERIOR`（「我自己的内部」）。
- 地图东边（右侧）和几个角是雾：柔和的白雾盖过去，海岸线的字进到雾里逐渐变淡、断成虚线；雾里斜体写 `FOG` 的几条，「2026 年 6 月以后」放在最东边。
- 开阔的海里一座小岛 `PHANTOM`：画得特别清楚笃定（海岸线、水纹、一座小山都齐全），朱红标签「此岛可能并不存在」，下面小字括注。这是这张图最要紧的笑点：边界之内也会错。
- 一条朱红虚线小路 `PATH` 从大陆的一个港口出发，穿过陆地，走进东边的雾里，旁边标「你自己的路」。
- 大块水域写 `SEAS` 的名字（拉开字距的斜体）；一角放罗盘玫瑰，用字做放射线，标 `COMPASS`；左上或上方一个装饰框写 `TITLE` / `SUBTITLE`；下方放 `SCALE` 比例尺，刻度故意不均匀。
- 缩略图：一眼是一张旧地图，边缘有雾。100%：所有线都是字，笑点能找到。别挤满：海要有呼吸。
